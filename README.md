# awesome-machine-translation
A list of machine translation websites where you can input text to translate into one language (some with available Android apps). Most of these are neural machine translation apps and websites. Any more to recommend would belong in the Issues tab.

## Indian languages 🇮🇳
* [Anuvaad Bhashini](https://anuvaad.bhashini.gov.in/text-to-text-translation) - Indian government machine translation project & translator under MeitY - contains 22 scheduled languages + additional few - [Android app](https://play.google.com/store/apps/details?id=com.dibd.bhashini)
* [Bharati Rajbhasha](https://bharati.rajbhasha.gov.in/) - Indian government project under Department of Official Languages - translation to and from 15 Indian languages and English

## Miscellaneous
* [Dzongkha NMT](https://nlp.cst.edu.bt/nmt/) - Dzongkha machine translation portal led by the Bhutanese College of Science and Technology | [Android app](https://play.google.com/store/apps/details?id=ddc.cst.dzongkhanlp)
* [Tilmoch AI](https://tilmoch.ai/en/translator) - translation site created in Uzbekistan - contains many Turkic languages, Georgian, Korean and Chinese languages | [Android app (Russian UI)](https://play.google.com/store/apps/details?id=com.tahrirchi.tilmoch&hl=en_US)
* [Monlam AI](https://monlam.ai/) - Tibetan-focused machine translation, with [Android app](https://play.google.com/store/apps/details?id=ai.monlam.monlamtranslate2)
* [DeepL](https://www.deepl.com/en/translator) - general purpose translation website from Germany | [Android app](https://play.google.com/store/apps/details?id=com.deepl.mobiletranslator)
* [Supertext](https://www.supertext.com/en) and [Helvetra](https://helvetra.ch/) - Swiss-developed machine translation websites (with many world languages in the case of Supertext and a few European languages for Helvetra)
* [Papago](https://papago.naver.com/) - South Korean machine translation website - with a main focus on CJK languages | [Android app](https://play.google.com/store/apps/details?id=com.naver.labs.translator)
* [Min'na no Jidou Hon'yaku @ TexTra](https://mt-auto-minhon-mlt.ucri.jgn-x.jp/content/menu/) (TexTra) - Japanese-developed machine translation software at NICT (supports many languages)
